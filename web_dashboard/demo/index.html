Extension test pages

Short, fictional pages written by the project team. Open each one in a normal Chrome tab with the paired MORVIX extension and check that the result matches the expectation. Every flagged or blocked page should then appear in the dashboard under Detection history and Alerts.

  • Threat in a chat message expect warningA direct threat against another person.
  • Self-harm post expect warningA first-person post about wanting to die.
  • Graphic description expect warningA gory description of an injury.
  • Recipe blog expect nothingOrdinary harmless content.
  • Crisis-line information expect nothingPrevention text that mentions suicide but is not harmful.
  • Sports report with idioms expect nothing"Killed it", "destroyed the defence", "bury them".

To test blocking: in the dashboard go to Domain & category rules (or Settings) and set a category to Block, or add a website rule blocking 127.0.0.1; then reload a page above. To test the offline behaviour, use Stop MORVIX from the Start menu and reload: the extension popup should say the last policy is still in effect.
